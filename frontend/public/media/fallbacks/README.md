# Assets de fallback generados localmente

Este directorio recibe las 100 fotografías curadas de la Generic Image Library V1 y sus variantes
de tarjeta. No se incluyen binarios de sustitución: ejecuta `npm run fallback-images:prepare --
--input <directorio-con-los-100-originales>` después de obtener manualmente los originales exactos
del manifiesto versionado.
